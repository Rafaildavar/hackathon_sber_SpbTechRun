# SberTechRun_bot — бот с mock LLM агентом

Кратко: проект содержит простой бот на `aiomax` и мок-агента `agent.py`, который принимает текст и локальные документы.

Как пользоваться (локально):

1. Установите зависимости:

```bash
python3 -m pip install --user -r requirements.txt
```

2. (Опционально) установите `certifi`, если возникают ошибки SSL на macOS — у нас уже указан в `requirements.txt`.

3. Запуск бота:

```bash
export TOKEN="<ваш токен>"
python3 bot.py
```

4. Тестирование мокового диалога:
- Отправьте боту обычное сообщение — оно будет передано в mock-агента и вы получите ответ.
- Чтобы протестировать ввод документа, отправьте сообщение вида:

```
/doc path/to/local/file.txt
```

  Бот прочитает указанный локальный файл и вернёт превью документа (mock-ответ).

Файлы:
- `bot.py` — адаптированный код бота, пересылает сообщения агенту.
- `agent.py` — mock LLM-агент с in-memory памятью и поддержкой локальных документов.

Дальше: подключите реальный LLM в `agent.handle_user_message` и добавьте постоянную память (sqlite/tinydb) при необходимости.
